# Diony

Reusable Next.js starter containing the application layout, navigation, UI components, and shared hooks. Product screens, backend integrations, and query caching have been removed. `src/api/client.ts` and `src/screens/auth/index.tsx` retain disabled source templates as comments.

## Development

- `pnpm install`
- `pnpm dev`
- `pnpm build`

Add routes under `src/app/`, reusable components under `src/components/`, and shared hooks under `src/hooks/`.
